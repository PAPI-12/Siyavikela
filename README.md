# Siyavikela Security Services — Brand Strategy Website

A responsive, editorial-style strategy website built around the supplied Siyavikela logo and the visual reference. The presentation includes a downloadable 24-page landscape PDF.

## Files

- `index.html` — website presentation; no external libraries or network assets required.
- `brand-strategy.pdf` — downloadable presentation PDF.
- `assets/` — logo artwork and unique local-inspired visual concepts.
- `build_pdf.py` — source used to generate the PDF (Python + Matplotlib + Pillow).

## Preview locally

Open `index.html` in a modern browser, or serve the folder over HTTP:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Visual and capability note

Neighbourhood photography and mockups of uniforms, vehicles, equipment, devices and stationery are AI-generated/local-inspired concept visuals for brand exploration. They are not documentary images and do not represent current Siyavikela operations, assets, authorisations, partnerships or service capacity. Service, team, market, registration and compliance information should be verified before any public release or launch.
